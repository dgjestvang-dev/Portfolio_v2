# Hvem er jeg?

Dette prosjektet er en enkel introduksjonsside laget som en del av studiet i UX/UI-design og frontend-utvikling ved Oslo Nye Fagskole.

Siden er basert på en tidligere oppgave hvor jeg laget en personlig introduksjonsside, og er videreutviklet med CSS, Flexbox, navigasjon og et kontaktskjema.

## Innhold

Siden inneholder:
- En kort introduksjon
- Informasjon om min bakgrunn
- Mine interesser
- Noen fun facts
- Et enkelt kontaktskjema

## Teknologi

Prosjektet er laget med:
- HTML5
- CSS
- Flexbox

Siden bruker semantiske HTML-elementer og er laget for å fungere på både brede og smale skjermer.

## Kontaktskjema

Kontaktskjemaet bruker HTML5-validering. Skjemaet er kun laget for å demonstrere struktur og styling og sender ikke data til en server.

## Kjøring

Prosjektet krever ingen installasjon. Klon repositoryet og åpne `index.html` i en nettleser.
